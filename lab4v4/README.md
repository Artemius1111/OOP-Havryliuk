# Лабораторна робота №4 (Варіант 4)

**Тема:** Успадкування, поліморфізм та перевизначення методів у C#  
**Мета:** Практично опанувати принципи успадкування та поліморфізму в об'єктно-орієнтованому програмуванні, навчитися створювати базові й похідні класи, використовувати виклик базового конструктора через `base`, а також розібратися у різниці між перевизначенням методів (`override`) та їх приховуванням (`new`).

## Хід роботи

Спочатку я розпакував репозиторій і відкрив його у VS Code. У терміналі створив проєкт lab4v4 командою dotnet new console. Далі у Program.cs реалізував базовий клас Animal з властивостями, конструктором, віртуальним методом MakeSound() та методом GetSpecies(). Потім описав похідні класи Dog та Cat, де викликав базовий конструктор через base, перевизначив MakeSound() за допомогою override, додав власні методи й реалізував приховування через new. У методі Main створив об'єкти, перевірив поліморфізм через масив Animal[] та продемонстрував різницю між override і new при зміні типу посилання, після чого успішно запустив проєкт через dotnet run.

## Контрольні запитання

1. **Що таке наслідування та наведiть приклад:**  
   Це механізм, який дозволяє похідному класу переймати поля та методи базового класу. *Приклад:* Dog успадковує загальні властивості від Animal.
2. **Призначення base:**  
   Використовується для виклику конструктора базового класу (base(...)) або його методів (base.MakeSound()) з похідного класу.
3. **virtual vs override та поліморфізм:**  
   virtual у базовому класі дозволяє перевизначити метод, а override у похідному реалізує нову логіку. Це забезпечує виклик методу залежно від реального типу об'єкта в пам'яті (динамічний поліморфізм).
4. **Навіщо new та його наслідки:**  
   Приховує метод базового класу без поліморфізму. При цьому виклик методу залежить від типу змінної-посилання, а не від самого об'єкта.
