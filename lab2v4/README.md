# Лабораторна робота №2: Клас із кількома конструкторами. Життєвий цикл об’єкта.

Виконав: Гаврилюк Артем
Варіант: №4 (Клас `Teacher`)
Тема: Клас із кількома конструкторами. Життєвий цикл об’єкта.
Мета: Навчитися реалізовувати перевантажені конструктори, дослідити порядок їх викликів та зрозуміти
основи життєвого циклу об’єкта в C#.

Хід роботи
У другій лабораторній ми створили клас Teacher, де за допомогою ланцюгового виклику : this() пов'язали два конструктори, щоб уникнути дублювання коду при створенні об'єктів. Для захисту даних ми додала перевірку стажу у властивості, заборонивши від'ємні значення, а також написали деструктор. Наприкінці у методі Main ми протестували створення різних викладачів та примусово викликали збирач сміття GC.Collect(), щоб наочно побачити, як .NET автоматично видаляє об'єкти з пам'яті.
